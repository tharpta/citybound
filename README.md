Citybound is a city building game with a focus on realism, collaborative planning and simulation of microscopic details. It is independently developed, open source and funded through Patreon.

## Revival Fork Status

This fork is in revival/bootstrap mode. The current goal is to keep the original
simulation observable, tested, and safe to modernize before resuming feature
work.

Verified local commands:

```sh
npm run build-compat
npm run test-compat
```
